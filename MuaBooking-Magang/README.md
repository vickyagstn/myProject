# 📖 Tentang Project

**MuaBooking Magang** merupakan aplikasi booking layanan Makeup Artist berbasis web yang dikembangkan untuk membantu proses reservasi pelanggan secara digital.

Melalui aplikasi ini, pelanggan dapat melakukan booking makeup, melihat status booking, serta memantau informasi reservasi. Admin dapat mengelola data pelanggan, jadwal booking, serta memonitor seluruh proses pemesanan dalam satu dashboard.

Project ini dikembangkan menggunakan **Google Apps Script** dengan **Google Spreadsheet** sebagai media penyimpanan data sehingga mudah dikelola tanpa memerlukan database server terpisah.
