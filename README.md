# 📖 Tentang Repository

Repository ini merupakan kumpulan project yang saya kembangkan sebagai media pembelajaran, pengembangan portofolio, serta implementasi berbagai teknologi modern dalam pembuatan aplikasi berbasis web.

Project-project yang terdapat pada repository ini mencakup berbagai bidang, seperti:

- 💰 Sistem Manajemen Keuangan
- 👨‍👩‍👧 Sistem Informasi Organisasi
- 💄 Sistem Booking Makeup Artist
- 🍽️ Sistem Kasir Digital
- 🚚 Sistem Monitoring Sales
- 📋 Sistem Kas & Arisan PKK

Seluruh project dibangun dengan pendekatan modern menggunakan React, Firebase, Supabase, Google Apps Script, dan Tailwind CSS.

# 💻 Cara Menjalankan Project

## React Project

Clone repository

```bash
git clone https://github.com/vickyagstn/myProject.git
```

Masuk ke folder project

```bash
cd nama-project
```

Install dependency

```bash
npm install
```

Menjalankan project

```bash
npm run dev
```

---

## Google Apps Script Project

1. Import project ke Google Apps Script.
2. Hubungkan dengan Google Spreadsheet.
3. Deploy sebagai Web App.
4. Jalankan melalui browser.
