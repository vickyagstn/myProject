# 📖 Tentang Project

**Sales Visit Manager** adalah aplikasi berbasis web yang dirancang untuk membantu pemilik toko dalam mengelola aktivitas kunjungan sales secara digital.

Aplikasi ini memudahkan pencatatan data sales, produk yang ditawarkan, riwayat kunjungan, serta pengeluaran toko. Selain itu tersedia dashboard untuk memonitor aktivitas sales sehingga seluruh data tersimpan secara terstruktur dan mudah diakses.

Project dikembangkan menggunakan **React**, **Vite**, **Tailwind CSS**, dan **Firebase** sebagai backend.

---

# 🎯 Permasalahan yang Diselesaikan

Aplikasi ini dikembangkan untuk membantu mengatasi beberapa permasalahan berikut.

- Sales datang ke toko tidak menentu.
- Sulit mengetahui kapan sales terakhir berkunjung.
- Sulit mengetahui produk yang pernah ditawarkan.
- Pengeluaran toko masih dicatat secara manual.
- Riwayat kunjungan sales tidak terdokumentasi dengan baik.

## 1. Clone Repository

```bash

cd myProject/sales-visit-app
```

---

## 2. Install Dependency

```bash
npm install
```

---

```bash

```
